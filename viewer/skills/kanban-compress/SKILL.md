# 压缩线程卷宗

在保留后续工作所需上下文的前提下，原地精简一份 `thread.md`。压缩的是线程文档，不是当前会话；减少重复和过程性叙述，不把卷宗改写成只反映当前状态的摘要。

## 定位并读取卷宗

1. 以当前会话工作目录为项目根。用户明确指定线程目录或卷宗路径时使用该目标；否则读取 `kanban/current`，定位 `kanban/threads/<目录名>/thread.md`。
2. 项目没有 `kanban/`、未指定线程且没有活跃线程，或目标卷宗不存在时，说明情况并停止。不要为了压缩创建目录、schema 或卷宗，也不要切换 `kanban/current`。
3. 完整读取目标卷宗后再编辑；需要识别可配置 label 时读取 `kanban/thread.schema.json`。不要读取或修改 `kanban/note.md`，不要为了压缩展开引用线程或关联 change 的内容。

## 压缩内容

保留原标题、核心 `status`、既有字段及顺序，包括 key 标记、字段说明、schema 外小节和未映射内容。核心 `goal` 与状态不属于压缩范围，除非用户在同一次请求中明确要求修改。以下名称均指核心 key；默认 label 仅用于旧卷宗回退识别。

- **completed**（默认“已完成的工作”）：按同一功能、问题或 change 合并记录。保留日期或范围、最终结果、仍有效的重要结论和验证结果；删除重复描述、操作流水、被后续结果取代的中间状态及不再有帮助的临时路径或一次性命令。不能合理合并时分别保留。
- **decisions**（默认“决策”）：保留仍有效的决定及原因，合并重复项；被取代的决策只留最新结论和必要原因，早期方案仅在能防止重复探索或解释约束时保留。仍影响后续选择的否决方向简要保留结论与原因。
- **goal 与未决事项**：保留未完成工作、限制、阻塞和继续工作所需标识。不要把计划改写成已完成。
- **changes、dependencies 及其他字段**：`changes` 是 Markdown 名称列表，`dependencies` 和其他 `reference` 字段是线程引用。保留 change 名称、线程序号、链接和自定义内容，仅去除完全相同的重复项；不要猜测归档状态或删除未经确认的悬空引用。

无法判断信息是否过时或重复时保留它。不得补写原文没有的日期、结果、决策或验证结论。

## 写入与复核

1. 基于完整原文生成压缩稿并写回目标 `thread.md`。保留 BOM、换行风格、稳定 key 标记和无关字段原文，避免无关格式变化。
2. 只修改目标卷宗，不修改其他线程、schema、操作手册、插件约定、代码或 OpenSpec 文件。
3. 写后复核标题、状态、字段和未映射小节是否完整，未决事项与有效决策是否保留，引用是否未被误改。
4. 报告卷宗路径、压缩前后字符数、主要合并或删除类别；有因不确定而保留的信息时一并说明。
